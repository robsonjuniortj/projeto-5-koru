# 📍 Projeto 5 Koru - Consulta CEP

Projeto desenvolvido durante a formação de Desenvolvedor de Software da Koru em parceria com o Grupo Boticário.

A aplicação realiza consultas de endereço a partir de um CEP utilizando a API pública ViaCEP, permitindo buscar informações como cidade, estado, bairro e logradouro.

---

## 🚀 Funcionalidades

✔️ Consulta endereço através do CEP  
✔️ Aceita CEP com ou sem hífen  
✔️ Integração com a API ViaCEP  
✔️ Exibe:
- Cidade
- Estado
- Bairro
- Logradouro

---

## 🛠️ Tecnologias Utilizadas

- JavaScript
- Node.js
- API ViaCEP

---
